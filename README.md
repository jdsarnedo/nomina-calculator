# Nómina Calculator - Colombia

Aplicación de cálculo de nómina para trabajadores colombianos con gestión de libranzas y préstamos.

## Características

- Cálculo de salario mínimo legal + auxilio transporte
- Recargos (festivo, nocturno, dominical, etc.)
- Horas extras
- Prestaciones sociales (EPS, pensión, ARL)
- Gestión de libranzas y préstamos con descuentos automáticos
- Autenticación con JWT
- Roles de administrador y usuario
- PWA (instalable en móviles)

## Tecnologías

- Backend: Spring Boot 3.x, MongoDB
- Frontend: Angular 17+
- Contenedorización: Docker & Docker Compose
